# OpenFlamma

The open financial ledger for humans and AI agents.

OpenFlamma gives businesses and their agents a shared ledger with permissions, human approval and a full audit trail. It does not hold, move or transfer money.

**Status:** Coming soon. We are building in private and will open the code once the first usable version is ready.
